# 文件结构说明

本文档用于说明当前文件夹中各文件和目录的作用。

## 根目录文件

| 文件 | 作用 |
|---|---|
| `DL课程设计.ipynb` | 最终课程设计 Notebook，包含完整报告内容、实验结果表格和图片输出。 |
| `DL课程设计.html` | 由 Notebook 导出的 HTML 报告，可直接用浏览器打开查看。 |
| `LPIA_LightUNet_low_light_enhancement.ipynb` | 原始主实验 Notebook，保存模型、训练、评估、传统增强方法等核心实现逻辑。 |
| `README.md` | 项目整体说明，介绍项目内容、推荐查看文件、运行方式、主要模型和结论。 |
| `requirements.txt` | Python 依赖列表，用于安装运行项目所需的基础库。 |
| `task.md` | 课程设计任务书/项目方案，描述课题背景、研究目标、技术路线和实验设计。 |
| `文件结构说明.md` | 当前文档，用于解释提交文件夹中的文件和目录。 |

## 运行脚本

| 文件 | 作用 |
|---|---|
| `run_lpia_training.py` | 单模型训练脚本。 |
| `run_strict_ablation.py` | 严格消融实验脚本，用于比较多个模型变体。 |
| `run_quick_ablation.py` | 快速消融实验脚本，用于快速检查实验流程。 |
| `run_generalization.py` | 泛化测试脚本，用于在无参考低光照图像上生成增强结果和指标。 |
| `run_benchmark.py` | 模型复杂度统计脚本，用于计算参数量、模型大小、FLOPs 和推理时间。 |
| `run_visualize_aux.py` | 辅助可解释性可视化脚本，用于导出 Gamma Map、Illumination Map、Dark Mask 等图像。 |
| `run_gradio_app.py` | Gradio 图像增强演示脚本。 |

## 代码与配置目录

| 目录 | 作用 |
|---|---|
| `lpia_project/` | 项目核心 Python 模块，包含模型注册、轻量模型实现和 Notebook 运行时加载工具。 |
| `configs/` | 实验配置文件目录，保存 LPIA-LightU-Net、LPIA-Former-Lite、Zero-DCE-Lite 等模型配置。 |
| `scripts/` | 辅助脚本目录，包含数据划分脚本、研究型分析图生成脚本和优势指标生成脚本。 |

## 数据目录

| 目录 | 作用 |
|---|---|
| `datasets/eval15/` | LOL-v1 测试集样本，包含低光照图像和对应参考图像。 |
| `datasets/generalization/` | 泛化测试数据目录，保存无参考低光照测试图像及数据来源说明。 |
| `datasets/our485/` | LOL-v1 训练集目录，当前提交版中保留训练集说明文件。 |

## 数据划分目录

| 文件/目录 | 作用 |
|---|---|
| `splits/lol_v1_seed42.json` | 固定随机种子生成的数据划分文件，记录 train/val/test 划分。 |
| `splits/lol_v1_seed42.csv` | CSV 格式的数据划分表，便于查看和核对。 |
| `splits/README.md` | 数据划分说明文档。 |

## 实验结果目录

| 文件/目录 | 作用 |
|---|---|
| `outputs/*.csv` | 实验结果表，包括消融实验、泛化测试、训练历史和优势指标统计。 |
| `outputs/benchmarks/` | 模型复杂度结果目录，保存参数量、FLOPs、推理时间等统计结果。 |
| `outputs/checkpoints/` | 模型权重目录，当前提交版中保留权重说明文件。 |
| `outputs/results/comparisons/` | LOL 测试集增强结果对比图。 |
| `outputs/results/generalization/` | 泛化测试增强结果和对比图。 |
| `outputs/results/aux_visualizations_lpia_former_lite_strict50/` | LPIA-Former-Lite 的辅助可解释性图像结果。 |
| `outputs/results/analysis_charts/` | 研究型分析图，如 PSNR/SSIM 对比、训练曲线、复杂度权衡图等。 |
| `outputs/results/advantage_charts/` | 优势指标分析图，如轻量化优势、泛化可用曝光评分和颜色偏移图。 |

## 文档目录

| 文件/目录 | 作用 |
