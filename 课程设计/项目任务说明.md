# 项目任务说明

## 一、项目名称

LPIA-LightU-Net 低光照图像增强项目

## 二、项目任务

本项目面向低光照图像增强任务，完成一个包含传统图像增强、轻量深度学习模型、物理先验引导模型、轻量 Transformer 混合模型、现代曲线增强基线和可视化分析的完整实验系统。

项目重点关注以下问题：

- 低光照图像整体亮度不足、暗部细节缺失和颜色失真问题。
- 传统增强方法参数固定、容易过曝或放大噪声的问题。
- 普通深度学习模型缺少明确光照先验、可解释性不足的问题。
- 模型在端侧轻量化场景下的参数量、推理速度和泛化稳定性。

## 三、项目目标

本项目的目标是设计并实现一种轻量化低光照图像增强方法，并通过多组实验验证其有效性。

具体目标包括：

- 实现 Gamma 校正、CLAHE、Retinex 等传统增强方法。
- 实现 Plain U-Net、Attention U-Net、Fixed Gamma U-Net、Learnable Gamma U-Net 等深度学习对比模型。
- 实现主方法 LPIA-LightU-Net，将可学习 Gamma 光照先验、光照引导注意力和轻量 U-Net 结合。
- 实现升级模型 LPIA-Former-Lite，引入 Retinex/Gamma 双先验和轻量窗口注意力。
- 实现现代基线 Zero-DCE-Lite，用于补充曲线估计类低光照增强方法对比。
- 建立固定 train/val/test 数据划分，保证实验结果可复现。
- 完成严格消融实验、泛化测试、复杂度分析和可解释性可视化。
- 形成可运行 Notebook、HTML 报告、实验脚本、结果图和项目说明文档。

## 四、核心方法

### 4.1 可学习光照先验

传统 Gamma 校正通常使用固定参数：

```text
I_enhance = I_low ^ gamma
```

固定 Gamma 难以适应不同图像区域的光照差异。本项目将 Gamma 参数扩展为像素级可学习映射：

```text
I_prior = I_low ^ Gamma(x, y)
```

其中 `Gamma(x, y)` 由轻量神经网络预测，使模型能够根据局部亮度自适应调整增强强度。

### 4.2 光照引导注意力

项目利用 Gamma Map、Illumination Map 或 Dark Mask 构造光照引导信息，使网络更加关注暗区细节恢复，同时降低亮区过增强风险。

核心思想是：

```text
暗区权重更高，亮区权重更低
```

该设计提升了模型对低照度区域的针对性，也增强了模型结果的可解释性。

### 4.3 轻量化增强主干

主模型采用轻量 U-Net 结构，通过控制基础通道数、限制最大通道数、使用局部注意力和保持较小参数规模，使模型适合端侧轻量化应用。

升级模型 LPIA-Former-Lite 在轻量 CNN 编码解码结构中加入瓶颈层窗口注意力，用较低额外计算量提升局部和区域上下文建模能力。

## 五、数据集与数据划分

项目主实验使用 LOL-v1 数据集：

- `our485`：用于训练和验证。
- `eval15`：用于测试。

项目使用固定随机种子划分：

- `train`：435 对图像。
- `val`：50 对图像。
- `test`：15 对图像。

数据划分文件位于：

```text
splits/lol_v1_seed42.json
splits/lol_v1_seed42.csv
```

项目还包含泛化测试数据目录，用于评估模型在非训练场景下的增强稳定性。

## 六、实验内容

### 6.1 传统方法对比

项目实现并对比以下传统增强方法：

- Gamma 校正。
- CLAHE。
- Retinex。

这些方法作为可解释、低复杂度的基础增强基线。

### 6.2 深度模型对比

项目实现并对比以下深度学习模型：

- Plain U-Net。
- Attention U-Net。
- Fixed Gamma U-Net。
- Learnable Gamma U-Net。
- LPIA-LightU-Net。
- LPIA-Former-Lite。
- Zero-DCE-Lite。

这些模型覆盖普通编码解码网络、先验引导网络、轻量注意力网络和现代曲线估计网络。

### 6.3 消融实验

项目围绕 LPIA-LightU-Net 的核心模块进行消融：

- 不使用光照先验的基础 U-Net。
- 使用固定 Gamma 先验。
- 使用可学习 Gamma 先验。
- 加入光照引导注意力。
- 加入结构相似性损失。
- 加入先验平滑约束。

消融实验用于验证可学习先验、注意力模块和损失函数设计是否有效。

### 6.4 泛化测试

项目在额外低光照图像上进行泛化测试，重点观察：

- 暗区亮度是否得到提升。
- 亮区是否出现过曝。
- 颜色是否自然。
- 纹理和边缘是否被保留。
- 不同方法在真实低光照图像上的稳定性。

### 6.5 复杂度分析

项目统计模型的轻量化指标：

- 参数量。
- 模型大小。
- 推理时间。
- FPS。
- 不同模型之间的效果与效率权衡。

## 十、项目结论

本项目说明，低光照图像增强不能只依赖整体提亮，而需要同时考虑暗区恢复、亮区保护、结构保持、颜色自然度和模型效率。

传统方法实现简单、速度快，但对不同图像的适应能力有限。普通 U-Net 具备学习能力，但缺少明确的光照约束和可解释性。LPIA-LightU-Net 通过可学习光照先验和光照引导注意力，使模型能够更加有针对性地处理暗区，并在端侧轻量化场景下保持较低复杂度。

升级模型 LPIA-Former-Lite 进一步引入轻量注意力机制，补充了区域上下文建模能力。Zero-DCE-Lite 作为现代曲线增强基线，为项目提供了不同技术路线的横向比较。

整体来看，本项目完成了从问题建模、方法设计、代码实现、实验验证、结果分析到可视化展示的完整流程。
